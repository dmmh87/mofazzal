# Website: Prof. M. Mofazzal Hossain

All files sit at the top level of the repository. There are no folders.

| File | What it is |
| --- | --- |
| `content.js` | All website text. **This is the file you edit.** |
| `editor.html` | A form for adding or editing research topics with pictures. Open `https://YOUR-USERNAME.github.io/editor.html` (or `/REPO-NAME/editor.html`) |
| `index.html`, `style.css` | Layout and navy-and-brass design. Only change these for design changes. |

## Publish
1. Create a repository: either `USERNAME.github.io` (if this account has no site yet), or any name such as `mofazzal-hossain` (if `USERNAME.github.io` is already used for another site). Set it to **Public**.
2. **Add file → Upload files** → select all files → **Commit changes**.
3. **Settings → Pages** → Deploy from a branch → **main** / **(root)** → Save.
4. The site appears at `https://USERNAME.github.io` or `https://USERNAME.github.io/REPO-NAME/`.

## Add the photo
Upload a portrait named `photo.jpg` (4:5 shape works best), then in `content.js` set `"photo": "photo.jpg"`. Until then the site shows the initials "MH".

## Add a research topic with pictures
Open `editor.html` on the live site → **Add new research topic** → fill in the text and add pictures → **Download files** → upload the downloaded files to the repository → **Commit changes**.

## Other edits
Open `content.js` on GitHub → pencil icon → edit → **Commit changes**. Instructions are at the top of the file.
